# API and UI Automation Projects

This repository contains test automation frameworks, suites, and projects covering both **API** and **UI** testing using Postman, Python, and Playwright.

---

## 📁 Repository Structure

### 01. Postman API Testing (`01-postman-api-testing/`)
Automated API test suite built in **Postman** covering Recommendation and Blacklist services.
* **Key Scenarios:** Dynamic variables, JWT Authentication, JSON Schema, and Status Code assertions.
* **Bug Reports:** Detailed documentation of critical API issues discovered during testing.
