# SQL Database Testing & Complex Queries (Northwind DB)

## 📌 Overview
This directory contains SQL queries developed for database validation and data integrity testing using the **Northwind** relational database.

## 🔑 Key SQL Concepts Demonstrated
* **Multi-Table JOINs:** Executing `INNER JOIN`, `LEFT JOIN`, and `FULL OUTER JOIN` across multiple related tables.
* **Data Aggregation:** Advanced grouping (`GROUP BY`, `HAVING`) and aggregate functions (`SUM`, `AVG`, `COUNT`, `MAX`, `MIN`).
* **Filtering & String Matching:** Complex `WHERE` conditions, `LIKE` wildcard matching, and handling `NULL` checks (`IS NULL`).
